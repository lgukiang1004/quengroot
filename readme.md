# 퀸장그루터기 🌱 · 퀸즈 장로교회 청년부 온라인 교회

그루터기 모여라! 마당에서 만나고, 본당에서 기도하고, 성경 읽는 공간에서 말씀 읽고, 비전실과 301호에서 쉬어가는 3D 온라인 공간이에요. 🎄 지금은 크리스마스 장식 중!

- **🏡 마당**: 교회 앞마당이에요. 건물 앞 문 4개로 본당 · 비전 · 성경 읽는 공간 · 301호에 들어가요. 가운데 큰 크리스마스 트리가 반짝이고 눈이 내려요. 건물 오른쪽 **놀이터**에서 "🛷 눈썰매"를 누르면 언덕에 올라가 썰매를 타요 (다른 사람에게도 보여요).
- **🙏 본당 (기도하는 공간)**: 장의자에 앉아 기도제목을 말풍선으로 올려요 (익명 가능). "🙏 기도하기"를 누르면 눈을 감고 손을 모아요. 게시판에는 **오늘의 말씀**과 **공동 기도제목**, **오늘 기도하고 간 사람**이 보여요.
- **📖 성경 읽는 공간**: "📖 본문 읽기"로 개역한글 성경을 바로 읽어요. "✓ 다 읽었어요"를 누르면 통독표에 체크되고 발자취에 남아요.
- **🕊 비전**: 원목 테이블에 둘러앉아 이야기 나누는 곳이에요. 검은 소파에 앉은 뒤 "🛌 눕기"로 누울 수 있고, 창문 옆 **방명록 보드**에 쪽지를 붙일 수 있어요.
- **🛋 301호 (청년부 아지트)**: 소파에 앉은 뒤 "🛌 눕기"로 누워서 쉴 수 있어요. 책상 위 **방명록 보드**를 누르면 쪽지를 붙일 수 있어요.
- **👣 발자취 대시보드**: 누가 다녀가서 기도하고 어떤 말씀을 읽고 갔는지 모아 봐요 (오늘 / 최근 7일). 3D 공간에도 오늘 기도한 자리에는 🌱 씨앗이, 말씀 읽은 자리에는 📖 성경이 놓여요. 기도 내용은 저장되지 않아요.
- **오늘의 말씀**: 개역한글 330구절 중에서 매일 자동으로 바뀌어요 (뉴욕 날짜 기준, 모두 같은 말씀).
- **🐙 타코야끼 · 🐟 붕어빵 트럭** (놀이터 앞): 트럭에 들어가서 미니 게임으로 직접 만들고, 트럭에 두면 친구들이 하나씩 받아가요. 간판에 지금까지 만든 개수가 보여요. 붕어빵 수익금은 캄보디아 벧엘 국제학교 아이들 장학금으로 쓰여요 💛
- **간식 들고 다니기**: 북카페(성경 읽는 공간) 카운터의 간식 선반에서 라면 · 아아 · 아이스크림 · 라떼 · 차 · 핫초코를 골라 들고 다녀요. 화면 아래에서 😋 먹기, 🎁 친구에게 주기를 할 수 있어요.
- **🐱 마당 고양이 5마리**: 샤샤 ♂ · 까맹이 ♀ · 껌딱지 ♀ (검정 큰/중간/작은 고양이), 탐 ♂ · 브라우니 ♂ (늘씬한 고등어)가 마당을 돌아다녀요. 누르면 쓰다듬어져요.
- **🐾 고양이 콘도** (교회 건물 왼쪽): 건사료 · 캔사료 · 츄르 · 물을 주면 고양이들이 달려와서 먹어요. "오늘 밥 몇 번, 마지막에 누가"가 칠판에 보여요.
- **캐릭터**: 남/여, 머리, 안경, 옷 색에 더해 손에 드는 것(기타 · 탬버린 · 커피 · 성경책 · 마이크)과 착용(산타 모자 · 털모자 · 목도리 · 루돌프 머리띠)을 고를 수 있어요.
- **📢 이번주 공지**: 비전 · 301호 게시판 맨 위에 보여요. 관리자(⚙️)에서 올려요.
- **📲 앱으로 쓰기**: 위쪽 📲 버튼을 누르면 홈 화면에 그루터기 앱 아이콘을 만들 수 있어요 (아이폰은 사파리, 삼성폰은 크롬·삼성 인터넷).
- **👥 지금 여기 있는 사람**: 오른쪽 위 숫자를 누르면 목록이 나오고, 이름을 누르면 그 사람을 찾아가요.
- 그 밖에: 캐릭터 꾸미기, 📜 기도 벽, ⚙️ 관리자, 배경음, 비속어 필터, 신고 3회 자동 숨김

## 1단계 · 먼저 데모로 보기 (설정 없이)

폴더째 넷리파이에 올리면 바로 **데모 모드**로 열려요. 가상 친구들이 있는 미리보기이고, 데모 관리자 비밀번호는 `demo`예요.

## 2단계 · Supabase 설정 (무료, 실시간 공유용)

1. https://supabase.com 에서 프로젝트를 만들어요.
2. **SQL Editor → New query**에서 `supabase-setup.sql` 내용을 붙여넣고, `'여기에-관리자-비밀번호'`를 원하는 비밀번호로 바꾼 뒤 **Run**.
3. 이어서 `supabase-update-footprints.sql` 내용도 붙여넣고 **Run**. (발자취 · 비전/301호 방명록 · 이번주 공지 · 푸드 트럭 숫자 · 고양이 밥 기록용이에요. 이미 쓰던 프로젝트라면 이것만 하면 돼요. 여러 번 실행해도 괜찮아요.)
4. **성경 퀴즈**를 쓰려면 `supabase-update-quiz.sql`도 붙여넣고 **Run**. (출제 범위 · 퀴즈 랭킹용이에요. 여러 번 실행해도 괜찮아요.)
5. **함께하는 기능**(모임 시간표 · 설교 본문 · 계절/밤 설정 · 통독 챌린지 · 감사 나무 · 운동장 랭킹 · 알림 구독)을 쓰려면 `supabase-update-community.sql`도 붙여넣고 **Run**. (여러 번 실행해도 괜찮아요.)
   - **1부/2부 나누기(공지·퀴즈·함께 성경 읽기) · 1부 관리자 · 찬양팀 곡 악보**를 쓰려면 `supabase-update-groups.sql`도 붙여넣고 **Run**. 그다음 사이트 ⚙️ 관리자(전체 관리자 비밀번호) → 🔑 비밀번호 관리에서 1부·찬양팀 비밀번호를 정해요.
   - **🎸 찬양팀 연습실**의 📝 추천 찬양 게시판을 쓰려면 `supabase-update-praise.sql`도 붙여넣고 **Run**. (연습실 발자취도 같이 남아요. 연주·합주는 설정 없이 바로 돼요. 여러 번 실행해도 괜찮아요.)

### 🔔 폰 알림 켜기 (선택)

누가 들어오거나 새 모임이 올라오면 폰으로 알림이 가게 하려면, Supabase에 알림 보내는 함수를 하나 올려야 해요. (카카오톡 알림은 보낼 수 없어요. 크롬·삼성 인터넷·홈 화면 앱 알림으로 가요. 아이폰은 홈 화면에 추가한 앱에서만 돼요.)

1. Supabase 왼쪽 메뉴 **Edge Functions → Secrets**에서 비밀 값 3개를 넣어요: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_EMAIL` (값은 따로 드린 `push-keys-SECRET.txt`에 있어요. 이 파일은 넷리파이에 올리지 마세요.)
2. **Edge Functions → Functions → Deploy a new function → Via Editor**를 눌러요.
3. 함수 이름을 **`notify`**로 하고, `supabase-functions/notify/index.ts` 내용을 전부 붙여넣은 뒤 **Deploy**.
4. `config.js`의 `pushPublicKey`는 이미 들어 있어요. 사이트에서 위쪽 🔔 버튼 → "알림 켜기".

## 3단계 · 키를 config.js에 넣기

Supabase **Project Settings → API Keys**에서 **Project URL**과 **publishable key**(예전 화면에서는 `anon` `public` 키)를 복사해서 `config.js`에 붙여넣어요.

```js
supabaseUrl: "https://abcdefgh.supabase.co",
supabaseKey: "sb_publishable_xxxxx 또는 eyJhbGciOi...",
```

> 이 키는 원래 공개되는 키라서 사이트에 넣어도 괜찮아요. **service_role / secret 키는 절대 넣지 마세요.**

## 4단계 · 넷리파이에 올리기

https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓으면 끝이에요. (이미 있는 사이트라면 사이트 → Deploys 화면 아래쪽에 폴더를 끌어다 놓으면 새 버전으로 바뀌어요.)

### 링크 공유 미리보기
카톡·문자로 링크를 보내면 **"그루터기모여라"** 제목과 `og-image.png` 그림이 나와요. 그림이 안 나오면 `index.html`의 `og-image.png` 두 군데를 `https://내사이트주소.netlify.app/og-image.png`처럼 전체 주소로 바꿔 주세요. (카톡은 미리보기를 한동안 저장해 두기 때문에, 바뀐 내용이 늦게 보일 수 있어요.)

## 알아두면 좋은 것

- 성경 본문(`bible/` 폴더)과 오늘의 말씀은 저작권 보호기간이 끝난 **개역한글**이에요. 공개 데이터에서 가져와 원문과 대조했어요.
- **통독표**는 각자 기기에 저장되고, **누가 무엇을 읽었는지**는 발자취 대시보드에 모두에게 보여요.
- 말풍선은 나가면 사라지지만, **발자취**(다녀감 · 기도함 · 읽은 말씀)는 30일 동안 남아요. 대시보드에서는 최근 7일까지 보여요.
- 폰에서 다른 앱에 갔다가 돌아오면 자동으로 다시 연결돼요. 연결이 끊기면 오른쪽 위에 "⚠ 다시 연결하는 중…"이 떠요.
- Supabase 무료 요금제는 일주일 넘게 아무도 안 쓰면 일시정지될 수 있어요. 그럴 땐 Supabase 대시보드에서 다시 켜면 돼요.
- 3D 그래픽은 three.js(MIT 라이선스, `lib/` 폴더)로 그렸어요.
